# Project notes

- **All games are mobile-only.** Design for phones in portrait: touch input (tap, swipe),
  44px+ tap targets, no hover states, no keyboard shortcuts or right-click, no desktop-only hints.
  Games run as single-file HTML pages and must fit one screen without scrolling.
- **Use Gemini for generated images** (game art, backgrounds, illustrations). Keep animated
  elements (balls, particles, effects) drawn in code.
